# One opt-in order reminder

Default off. An administrator must enable the workflow, product tab and collection form. A signed-in customer explicitly requests one reminder from their own completed order's account page using a WordPress nonce. No guest guessing, checkout preselection, bulk backfill or external email provider. Queue one reminder seven days after completion/consent (whichever is later). Link to one still-public, unrefunded product form. Customer opt-out, existing product review, order cancellation/refund/deletion, configuration disablement or identity/email mismatch suppress sending.

Native single WP-Cron event with stable [order ID] arguments; visits or a configured system cron must drive it. At most three pre-send retries for temporary missing WooCommerce availability. Atomic conditional option claim, checking current order consent and account suppression generation, before wp_mail prevents parallel/replayed jobs sending twice. wp_mail success means transport acceptance, not inbox delivery. Failed/ambiguous mail and interrupted claims are terminal, with no automatic resend because core mail has no provider idempotency key. Record only state, numeric references and timestamps, no message body or email in options. Order requests and opt-out participate in native privacy export/erasure and per-site uninstall cleanup. Disabling/deactivation stops delivery, reactivation rechecks eligibility.

The customer can cancel from the account order page. The email includes a product-bound suppression link carrying a signed opaque token, no email address. A GET only shows a confirmation form: suppression requires POST to avoid mail-scanner link clicks. Do not allow forwarded links to expose order details. Development tests intercept all mail and use fictional example.test identities. No real sending is authorized by this development work.

Sources: https://developer.wordpress.org/reference/functions/wp_schedule_single_event/ , https://developer.wordpress.org/reference/functions/wp_mail/ , https://woocommerce.github.io/code-reference/files/woocommerce-templates-order-order-details.html .
